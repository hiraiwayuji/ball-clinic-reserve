# V-ARC 週次改善提案 2026-10-04

## 今週の要約（3行）

他社比較で際立ったのは「患者の離反をシステムが自動で検知して動く」機能の有無。V-ARC は来院データは蓄積されているのに、まだその予兆を能動的にスタッフへ知らせる仕組みがない。今週は「休眠患者の自動検知」「RFM顧客セグメント分類」「予約枠ヒートマップ」「施術後NPS配信」「スタッフ個人目標カード」「シフト後一言メモ」の6本を提案する。

---

## 提案 1: 休眠患者の自動検知 & ワンタップ LINE 呼び戻し配信

**観点:** ①利用者(受付・院長)が使いやすくなる / ②データ分析・経営判断がしやすくなる

### 背景・きっかけ

接骨院向け CRM の比較記事（リピッテ、HONEY LINK など）で「最終来院から X 日超で患者をリスト化し、自動 LINE を送る」機能が差別化ポイントとして強調されていた。海外では Pabau（[https://pabau.com/blog/patient-retention-software/](https://pabau.com/blog/patient-retention-software/)）が「re-engagement campaign」として組み込み済み。V-ARC の分析画面には来院比較・曜日分析はあるが、「今まさに離れかけている患者」を能動的にリスト化・通知する機能がない。

### 提案内容

**マーケティング > メッセージ** 画面に「休眠患者リスト」タブを追加する。

- 院ごとに「通常来院間隔（例: 7 日）＋ 猶予日数（例: 7 日）= 14 日超で来ていない患者」をヒットさせる閾値を設定できる（設定 > 院内設定）
- リストには患者名・前回来院日・経過日数・来院回数が表示され、チェックボックスで絞り込んで一括 LINE 配信できる
- 配信文は AI が患者の来院回数・施術部位傾向を元に自動文面生成（既存 `ai-marketing.ts` を流用）
- ダッシュボードに「今日の離反リスク患者 X 名」バッジを表示（院長ロールのみ）

### 期待できる効果

- 院長・受付が顧客リストを手動でスキャンしなくてよくなる
- 業界データでは自動フォローアップで 35% のリピート率向上事例あり（rehasaku.net/media/receipt/4091/）

### 実装イメージ

- 関連ファイル: `src/app/actions/analytics.ts`（来院間隔クエリ追加）、`src/app/actions/line-marketing.ts`（セグメント配信）、`src/app/admin/marketing/message/page.tsx`（タブ追加）、`src/app/admin/dashboard/DashboardClient.tsx`（バッジ表示）
- 難易度: **中**（新規クエリ + 既存 LINE 配信 UI の拡張）

**優先度: 高** — データは既にある。実装工数の割に経営インパクトが大きい。

## 提案 2: RFM 顧客セグメント自動分類 & セグメント別 LINE キャンペーン

**観点:** ②データ分析・経営判断がしやすくなる

### 背景・きっかけ

美容室向け POS「SalonAnswer」「CROSS POINT」は RFM 分析（Recency: 最終来院日・Frequency: 来院頻度・Monetary: 累計支払）をコア機能として持ち、「セグメントごとに異なる DM を出す」が常識化している（[https://cross-point-system.jp/function/analytics02.html](https://cross-point-system.jp/function/analytics02.html)）。接骨院業界ではまだ珍しいが、患者の「囲い込み」という意味でまさにフィットする。

### 提案内容

**経営評価** または **分析** 画面に「顧客セグメント」タブを追加する。

- 自動で全患者を 4 グループに分類:
  - 🟢 **優良客**（高頻度・高単価・直近来院）
  - 🟡 **育成客**（中頻度・低〜中単価）
  - 🟠 **離反予備軍**（頻度落ちている・単価高め → 取りこぼしたくない）
  - 🔴 **休眠客**（90 日以上未来院）
- 各グループのバブルサイズ＝人数、クリックでメンバーリスト表示
- 「このセグメントに LINE 配信」ボタンで `marketing/message` 画面へセグメント条件付きで遷移

### 期待できる効果

- 「誰に何を送るか」の判断が視覚的・即断できる
- 優良客への感謝 DM → 口コミ効果、休眠客へのクーポン → 呼び戻し、と施策が明確化

### 実装イメージ

- 関連ファイル: `src/app/actions/analytics.ts`（RFM 計算クエリ追加）、`src/app/actions/adminCustomers.ts`（セグメントタグ付き顧客取得）、`src/app/admin/analytics/page.tsx`（タブ追加）、`src/app/admin/marketing/message/page.tsx`（セグメント条件受け渡し）
- 難易度: **中**（SQL 集計ロジック + UI タブ追加）

**優先度: 高** — 既存データの活用拡張のみ。新規 UI も比較的シンプル。

## 提案 3: 予約枠ヒートマップ「稼働率の見える化」

**観点:** ②データ分析・経営判断がしやすくなる

### 背景・きっかけ

海外の予約 SaaS Pabau・WaitWell は「appointment utilization heatmap」を提供しており、「どの曜日・時間帯に空きが多いか」を一目で把握できる（[https://pabau.com/blog/patient-retention-software/](https://pabau.com/blog/patient-retention-software/)）。V-ARC の分析画面には「曜日別来院数」グラフはあるが、時間帯 × 曜日のマトリクス（何 % 埋まっているか）はない。経営判断（割引時間帯の設定・スタッフシフト調整）に使える。

### 提案内容

**分析** 画面に「予約枠ヒートマップ」ウィジェットを追加する。

- X 軸: 曜日（月〜日）、Y 軸: 時間帯（9:00〜18:00 など院の営業時間）
- セル値: その時間帯の過去 4 週間の平均稼働率（%）
- 色は赤（高稼働）〜青（低稼働）のグラデーション
- 院長がセルをクリック → その時間帯の予約一覧をポップオーバーで確認
- 「空き多い時間帯を特定して割引キャンペーン」ボタン → `marketing/message` へ誘導

### 期待できる効果

- 「水曜 15 時台がいつも空いている」を数字で見え、割引・スタッフ削減の判断根拠になる
- 院のキャパシティ最大化 → 売上向上

### 実装イメージ

- 関連ファイル: `src/app/actions/analytics.ts`（時間帯 × 曜日集計クエリ追加）、`src/app/admin/analytics/page.tsx`（ヒートマップ UI 追加）
- 難易度: **小〜中**（クエリは単純、UI は CSS グリッドで実装可能）

**優先度: 高** — 実装コスト小で院長の経営判断に直結する「気づき」を提供できる。

## 提案 4: 施術後 1 問 LINE アンケート（患者 NPS）& スタッフ別満足度トラッキング

**観点:** ①利用者(受付・院長)が使いやすくなる / ②データ分析・経営判断がしやすくなる

### 背景・きっかけ

船井ヘルスケアのコラム「整骨院で患者アンケートを活用して満足度を上げるには？」（[https://funai-healthcare.funaisoken.co.jp/blogs/column/se038](https://funai-healthcare.funaisoken.co.jp/blogs/column/se038)）では、来院後のフィードバック収集が口コミ改善の最速手段と論じている。現在 V-ARC の `questionnaire.ts` は問診票（来院前の症状入力）のみで、施術後の満足度収集は未実装。海外では Pabau が EHR に patient satisfaction tracking を内包済み。

### 提案内容

施術完了（売上記帳）後、担当スタッフ経由で患者の LINE へ「施術後アンケート」を自動送信する仕組みを追加。

- **送信タイミング**: 売上記帳が保存された X 時間後（デフォルト 2 時間、設定で変更可）に LINE PUSH
- **アンケート内容**: 1 問のみ「本日の施術はいかがでしたか？ ★1〜5 でお答えください」＋自由コメント（任意）
- **結果の蓄積**: `経営評価` 画面に「患者満足度」タブを追加。月別 NPS スコア推移グラフ、スタッフ別平均スコアの棒グラフを表示
- **受付での活用**: 5 点満点のコメントは自動でダッシュボードの「今日の声」カードに表示

### 期待できる効果

- スタッフの施術品質が可視化され、高評価スタッフの表彰・低評価の早期改善フィードバックに使える
- 患者が「声を聞いてもらえる」体験でリピート率向上

### 実装イメージ

- 関連ファイル: `src/app/actions/sales.ts`（記帳完了 hook 追加）、`src/app/actions/line-marketing.ts`（1問アンケート送信）、`src/app/admin/evaluation/page.tsx`（満足度タブ追加）、`src/app/admin/dashboard/DashboardClient.tsx`（今日の声カード）
- 難易度: **中**（LINE Messaging API のアンケート用リッチメニュー or クイックリプライ設計が必要）

**優先度: 高** — スタッフモチベーションと患者リピートの両方に直結する「一石二鳥」施策。

## 提案 5: スタッフ個人目標カード & 院内進捗シェア

**観点:** ③スタッフ管理がしやすく、スタッフのモチベーションが上がる

### 背景・きっかけ

IQVIA の「スタッフの自発性を引き出す組織マネジメント」セミナー（[https://www.iqvia.com/ja-jp/locations/japan/events/2025/06/organizational-management-that-draws-out-staff-initiative](https://www.iqvia.com/ja-jp/locations/japan/events/2025/06/organizational-management-that-draws-out-staff-initiative)）および実際の医療機関の経営方針発表会の事例から、「目標を全員で見える化・共有すること」が自発性と達成感の源泉と確認。V-ARC の現リーダーボードは「アクション数の合計」のみで個人の成長目標がない。

### 提案内容

**ランキング** 画面をリニューアルして「スタッフ個人目標カード」を追加。

- 各スタッフが月初に自分の目標を設定: 例「担当予約件数 80 件」「物販売上 ¥30,000」「患者満足度平均 4.5 以上」
- 目標はプルダウン + 数値入力で設定（自由記述も可）
- 院内全員がカードを閲覧できる（他人の進捗が見え、良い意味でのプレッシャーと刺激になる）
- 達成したらカードに「🏆 達成済み」バッジが付く。院長は「コメント/いいね」が押せる
- 月末に自動で達成/未達成の集計をまとめて院長にダッシュボード通知

### 期待できる効果

- スタッフが「頑張り方」を自分で選べるため主体性が上がる
- 院長が 1on1 のネタに使えて、「〇〇さん、あと 5 件だね、応援してるよ」が言いやすくなる

### 実装イメージ

- 関連ファイル: `src/app/admin/leaderboard/page.tsx`（UI リニューアル）、`src/app/actions/security.ts`（getLeaderboard 拡張 or 別アクション追加）、Supabase に `staff_monthly_goals` テーブル新設
- 難易度: **中**（テーブル追加 + カード UI 実装）

**優先度: 中** — 採用・定着コストが下がる中長期施策。先に提案 1〜3 の売上直結案を片付けた後に取り組むのが現実的。

## 提案 6: シフト終了後「今日の一言」メモ & コンディションカレンダー

**観点:** ③スタッフ管理がしやすく、スタッフのモチベーションが上がる

### 背景・きっかけ

医療者の働きがいに関する調査（[https://bcmedi.jp/blog/rewarding-work/](https://bcmedi.jp/blog/rewarding-work/)）では「感謝されている実感・孤独感を感じない職場」が定着率を左右する最大因子とされる。現在 V-ARC の勤怠管理は出退勤の記録のみで、スタッフのコンディション把握は院長の"感" 頼み。カジュアルな一言メモで「見てもらえている」を演出しつつ、離職サインを早期キャッチできる。

### 提案内容

スタッフが退勤を打刻した直後、管理画面に「今日の一言」入力欄を表示する（任意、スキップ可）。

- 入力欄: テキスト 100 字以内 ＋ 今日のコンディション絵文字 5 択（😊 普通 😄 最高 😅 疲れた 😤 イライラ 😔 しんどい）
- 院長は **スタッフ予定** 画面に「コンディションカレンダー」タブが表示され、スタッフ × 日付のカレンダーに絵文字が並ぶ
- 「しんどい」が 3 日以上連続したスタッフは院長のダッシュボードに「⚠️ 要フォロー」アラートが出る
- スタッフ同士は互いのコンディションを見ない（院長 or 管理者のみ閲覧可）

### 期待できる効果

- 院長が「最近どう?」と声がけするきっかけを数字で得られる
- スタッフが「見てもらえている感」を持てて定着率改善
- 離職サインを早期把握 → 採用コスト削減

### 実装イメージ

- 関連ファイル: `src/app/admin/attendance/page.tsx`（退勤直後ダイアログ追加）、`src/app/actions/attendance.ts`（一言メモ保存 action 追加）、`src/app/admin/my-schedule/page.tsx` or `settings/staff-schedule/`（コンディションカレンダービュー追加）、`src/app/admin/dashboard/DashboardClient.tsx`（要フォローアラート）、Supabase に `staff_condition_logs` テーブル新設
- 難易度: **小〜中**（退勤モーダル追加 + ログ保存が中心。カレンダーは既存 UI を転用可）

**優先度: 中** — 実装コスト小で「スタッフへの配慮」を形にできる。人材不足が深刻な時代に差別化になる。
