# V-ARC 週次改善提案 2026-10-25

## 今週の要約（3行）

キャンセル待ちの「手動連絡」を自動化し、空き枠の取りこぼしをゼロにする仕組みが最優先。  
「2〜3回来て離れる患者」を自動検出してケアDMを送る機能は、競合の美容サロンCRMで既に当たり前になっており、接骨院でも即効性が高い。  
スタッフの貢献を「行動数」だけでなく「担当患者の売上と継続率」で見える化することで、院長とスタッフの対話を根拠ある評価に変える。

---

## 提案 1：キャンセル待ち → 自動LINE通知 ＋ ワンタップ確定

**観点:** ①利用者（受付・院長）が使いやすくなる

**背景・きっかけ**  
接骨院のキャンセル待ち管理は「電話で確認→連絡」という手動フローが主流。  
LINEステップの導入事例では「予約変更・キャンセルのLINE自動化でスタッフの電話対応を週10〜15件削減できた」という報告がある。  
参照: https://linestep.jp/2022/04/24/line-reserve/  
参照: https://ascii.jp/elem/000/004/377/4377227/

**提案内容**  
現状の `待機リスト` ページ（`src/app/admin/waitlist/page.tsx`）にはキャンセル待ち一覧が表示されるが、「キャンセルが発生した際に誰かに通知する」機能はない。以下の流れを追加する：

1. 予約がキャンセルされると（`manage-reservation.ts` の cancel 処理後）、同じ日時のウェイトリスト先頭の患者にLINEプッシュ通知を自動送信。
2. 通知メッセージ例：「○月○日 14:00 のご予約枠が空きました。15分以内にご確認ください → [確定ボタン]」
3. 15分以内に未応答の場合は次の順番の患者へ自動繰り下げ。
4. 受付画面にも「待機中の通知ステータス」が見えるバッジを追加。

**期待できる効果**  
- 受付スタッフの電話連絡コスト削減（推定：週3〜5件の電話対応を削除）  
- キャンセル枠の埋め戻し率向上（空き枠がゼロになるに近づく）  
- 患者体験の向上（「連絡が来た！」という満足感）

**実装イメージ**  
- 関連ファイル: `src/app/actions/manage-reservation.ts`（キャンセル後のフック追加）、`src/app/actions/line-marketing.ts`（LINE送信）、`src/app/admin/waitlist/page.tsx`（UI更新）
- LINE送信は既存の `line-marketing.ts` のアーキテクチャを流用可能
- キャンセル待ちテーブルに `notified_at`, `notified_status` カラム追加が必要（Supabase migration）
- 難易度: **中**（LINE送信の実績があるため、主にロジックとDB設計）

**優先度: 高**  
受付の電話対応コスト削減＋枠の埋め戻し、両方に即効性がある。既存のLINE連携基盤があるため追加コストが低い。

## 提案 2：「2〜3回の壁」離脱アラート ＋ 自動ケアDM

**観点:** ②データ分析・経営判断がしやすくなる ①利用者が使いやすくなる

**背景・きっかけ**  
美容室CRMの業界調査では「顧客の最大の離脱ポイントは2〜3回目訪問後である」ことが繰り返し指摘されている。接骨院でも「急性期が落ち着いたら来なくなる」という同様のパターンがある。  
美容室向けAI CRM「.Ai CRM for Beauty」（ASCII掲載、2024）は「担当者の次回空き枠を添えて再来店を促すメッセージを自動送信」する機能を持つ。  
参照: https://ascii.jp/elem/000/004/281/4281408/  
参照: https://www.shopowner-support.net/attracting_customers/salon/hair/beauty-salon-crm/

**提案内容**  
`src/app/actions/analytics.ts` の `countNewAndReturnVisits` を拡張し、以下のアラートを追加：

1. **顧客管理画面（`customers/page.tsx`）**に「要フォロー」フィルターを追加。  
   条件: 来院回数2〜4回 かつ 最終来院から21日以上経過 かつ 次回予約なし。
2. ダッシュボードの上部に「今週の要フォロー患者: N人」バッジを表示。
3. 一覧から対象患者を選択し、「ケアDM送信」ボタン1クリックでLINEメッセージ送信（テンプレート: 「○○さん、最近いかがですか？急なお身体の変化などあれば、いつでもご相談ください。ご予約はこちら→」）。
4. AI秘書機能（`ai-secretary.ts`）と連携し、患者ごとに施術履歴に沿ったパーソナライズDMを生成するオプションも将来的に追加可能。

**期待できる効果**  
- 離脱患者の再来院率向上（業界平均では再来院DMで5〜10%がリアクション）  
- 院長が「どれだけ患者が離れているか」を数値で把握できる  
- スタッフが毎朝アラートを見てフォローの優先度を即判断できる

**実装イメージ**  
- 関連ファイル: `src/app/actions/analytics.ts`（クエリ追加）、`src/app/admin/customers/page.tsx`（フィルター追加）、`src/app/admin/dashboard/DashboardClient.tsx`（バッジ追加）、`src/app/actions/line-marketing.ts`（送信）
- SQLで「2〜4回来院かつ最終来院21日超かつ次回予約なし」をフィルタリング
- 難易度: **中**

**優先度: 高**  
売上の維持に直結。毎月1〜2人の離脱防止でも年間数十万円規模の収益維持に繋がる。

## 提案 3：スタッフ別「担当患者継続率」ランキング

**観点:** ③スタッフ管理がしやすく、スタッフのモチベーションが上がる

**背景・きっかけ**  
現在の `leaderboard/page.tsx` は「アクション数（予約対応・売上記帳・経費登録など）」でランキングを出している。これは良い仕組みだが、「多く操作した人が上位」になりやすく、「患者に本当に貢献できているか」は見えにくい。  
国内のゲーミフィケーション市場は2024年で1,600億円規模（セガXD調査）まで成長しており、外発的報酬ではなく「内発的動機に根ざした設計が重要」という議論が主流になっている。  
参照: https://www.advertimes.com/20250630/article503607/  
参照: https://www.kaonavi.jp/dictionary/gamification/

**提案内容**  
リーダーボードを「アクション数」から「複合スコア」に進化させる：

1. **新指標「患者継続スコア」を追加**  
   - 担当患者の平均来院回数  
   - 担当患者の3ヶ月継続率（3ヶ月以内に5回以上来院）  
   - 担当患者の新患→再来転換率  
2. `leaderboard/page.tsx` に「今月のハイライト」タブを追加し、上記3指標それぞれのトップスタッフをバッジ表示。
3. スタッフ個人ページ（またはmy-schedule画面）に「自分のスコア詳細」を表示し、前月比を見せる。
4. 月末に院長向けサマリーをAI秘書（`ai-secretary.ts`）が自動生成：「今月最もリピートにつながった担当者: ○○さん（継続率82%）」

**期待できる効果**  
- 「患者を丁寧にフォローする」行動への動機づけ強化  
- 院長が根拠のある評価・フィードバックを行いやすくなる  
- スタッフが「単に入力を多くする」ではなく「患者と向き合う」指向に変わる

**実装イメージ**  
- 関連ファイル: `src/app/actions/security.ts`（getLeaderboard改修）、`src/app/admin/leaderboard/page.tsx`（UI追加）、`src/app/admin/my-schedule/page.tsx`（個人スコア追加）
- DBに担当スタッフ情報が予約テーブルに紐づいていれば集計可能
- 難易度: **中〜大**（集計SQLの設計とDBスキーマ確認が必要）

**優先度: 中**  
スタッフのモチベーションと院長の評価精度の両方を上げるが、DBスキーマ次第で工数が変わる。

## 提案 4：「自費 vs 保険」売上比率タイル（経営評価画面拡張）

**観点:** ②データ分析・経営判断がしやすくなる

**背景・きっかけ**  
接骨院の収益構造を理解するうえで「健康保険診療 vs 自費施術（マッサージ、整体コース等）vs 交通事故（自賠責）」の売上比率は極めて重要。  
マネーフォワードの記事によれば、自賠責の施術は1回あたり5,000〜10,000円以上になるケースがあり、健康保険の数百〜1,500円と比較して5〜10倍の単価差がある。院によって比率が異なるため、比率の可視化が経営判断に直結する。  
参照: https://biz.moneyforward.com/establish/basic/83684/

**提案内容**  
現在の `evaluation/page.tsx`（経営評価画面）にレーダーチャートや月次目標が並んでいるが、支払い方法・種別の内訳はない。以下を追加：

1. 経営評価画面の上部に「今月の売上内訳」ドーナツチャートを追加。  
   - 凡例: 自費施術 / 健康保険 / 自賠責 / その他  
   - 金額と比率の両方を表示  
2. 前月比の矢印（↑↓）と「自費比率 ○%（目標比 ○%）」テキストを横に表示。  
3. 年間推移グラフ（月別の積み上げ棒グラフ）で比率の変化を確認できるようにする。

**期待できる効果**  
- 院長が「今月は自費施術が増えた/減った」を一目で把握できる  
- 比率改善（例: 自費率向上）を戦略目標として設定しやすくなる  
- 確定申告・経営計画にも使いやすいデータになる

**実装イメージ**  
- 関連ファイル: `src/app/admin/evaluation/page.tsx`（UIにチャート追加）、`src/app/actions/sales.ts` or `evaluation.ts`（支払種別ごとの集計クエリ追加）、`src/app/admin/passbook/page.tsx`（記帳時に支払種別のタグ選択UIを強化）
- 売上記帳（passbook）に支払種別カラムが既にあるか確認が必要。なければ migration で追加
- recharts の `PieChart`/`BarChart` は既に `analytics/page.tsx` で使用中のため流用可能
- 難易度: **小〜中**（DBスキーマ次第）

**優先度: 中**  
実装コストが低い割に経営判断への貢献度が高い。passbook のデータ構造確認が先決。

## 提案 5：スタッフ向け「週次パーソナルレポート」自動LINE配信

**観点:** ③スタッフ管理がしやすく、スタッフのモチベーションが上がる

**背景・きっかけ**  
セガXDの2025年の国内調査では、ゲーミフィケーション（ポイント・バッジ等）に加え「情緒的価値へのアプローチ」が人材定着に寄与するとされている。具体的には「自分がどれだけ貢献できているか」を個人向けにフィードバックする仕組みが有効。  
現在の `shift-reminders` はシフトのリマインダーに特化しているが、スタッフが自分の成果を定期的に確認する手段がない。  
参照: https://www.advertimes.com/20250630/article503607/  
（セガXD ゲーミフィケーション市場規模調査）

**提案内容**  
毎週月曜朝（例: 8:00）に、各スタッフへ「先週の個人サマリー」をLINEで自動配信する：

```
【V-ARC 週次レポート】○○さん、お疲れ様です！
先週のあなた:
  📊 ランキング: 3位（先週比 +2位）
  👥 担当患者: 28名（うち新患 4名）
  💰 担当売上貢献: ¥182,000
  ✅ 完了タスク: 5件

今週のシフト: 月〜土（火曜休み）
院長からのひとこと: 「今週も頑張ろう！」← 院長が入力
```

1. AI秘書（`ai-secretary.ts`）で各スタッフ向けのサマリー文章を生成。  
2. シフトリマインダー（`shift-reminders.ts`）の配信基盤を拡張して利用。  
3. 院長用設定画面に「週次コメント」入力フォームを追加（全スタッフ共通の一言メッセージ）。  
4. 院長は任意で個別メッセージも入力可能（入力しなければデフォルト文章をAIが生成）。

**期待できる効果**  
- スタッフが毎週自分の貢献を「数字」で受け取り、自走的モチベーションが育つ  
- 院長の言葉（週次コメント）が全スタッフに届き、チームとしての一体感が増す  
- スタッフの離職率低下（「見えてる」「評価されてる」という感覚）

**実装イメージ**  
- 関連ファイル: `src/app/actions/shift-reminders.ts`（配信ロジック拡張）、`src/app/actions/ai-secretary.ts`（サマリー文章生成）、`src/app/admin/settings/page.tsx`（院長コメント入力UI追加）、cron 設定（毎週月曜実行）
- スタッフ別の集計データは提案3の「担当患者継続スコア」と同じDBクエリを流用可能
- 難易度: **中**（LINE配信基盤とAI生成は既存流用、データ集計がメイン工数）

**優先度: 中**  
スタッフのエンゲージメント施策として「手間がかからず効果が出やすい」。提案3と組み合わせると相乗効果が高い。
