# V-ARC 週次改善提案 — 2026-09-13

## 今週の要約（3行）

今週は「休眠患者の自動掘り起こし」「誕生月フォロー」「スタッフ達成バッジ」「来院間隔離脱スコア」「スタッフ週次コンディション申告」の5案を提案する。いずれも競合の接骨院・美容サロン向けSaaSや海外ツール（Square Appointments、SimplyBook）が既に実装し、ユーザーから高く評価されている機能を、V-ARCの文脈に翻訳したもの。既存の LINE配信・リーダーボード・顧客管理画面を基盤に組み合わせることで、中規模の追加実装コストで大きな効果が見込める。

---

## 提案 1 — 休眠患者「自動ウェイクアップ」一覧 + LINEワンクリック送信

**観点:** ① 受付・院長が使いやすくなる ／ ② データ分析・経営判断がしやすくなる

### 背景・きっかけ

接骨院向けSaaS「スリーズプロ」「Sattou」、および美容サロン向けCRM「リピクル」では、一定期間来院がない患者を自動で検知し、休眠顧客セグメントを作成する機能が 2025～2026 年にかけて標準搭載となっている。サロン向けの調査記事（ripia.jp, 2026）では再来店率 30% 向上の事例も紹介されており、最もコスパが高いリピート施策とされている。

- 参照: https://ripia.jp/column/40
- 参照: https://tol-app.jp/columns/1806

### 提案内容

1. **顧客管理画面**（`src/app/admin/customers/`）または**ダッシュボード**に「休眠患者ウィジェット」を追加。
   - しきい値（例: 60日 / 90日 / 180日）をセレクトで切り替え可能。
   - 「90日以上来院なし: ○○人」とカウントが一目でわかるバナーを表示。
2. **一覧画面**では患者名・最終来院日・来院回数・LINE連携状況を表示。
3. リストをまとめて選択し「LINEメッセージを送る」ボタン → 既存の `line-marketing.ts` / `line-campaign.ts` の送信フローへ繋ぐ（テンプレート選択 → 一括送信）。
4. 送信ログを記録し、「送信済み/未送信」フラグを顧客テーブルに保持。

### 期待できる効果

- 「誰を呼び戻すべきか」を毎日手作業で確認する業務がゼロに。
- 休眠患者への定期フォローが仕組み化され、月間来院数の底上げが見込める。

### 実装イメージ

- 関連ファイル: `src/app/actions/adminCustomers.ts`（最終来院日クエリ追加）、`src/app/admin/customers/CustomersTable.tsx`（フィルタ追加）、`src/app/actions/line-marketing.ts`（既存流用）
- 難易度: **中**（Supabase クエリで `last_visit_date < now() - interval '90 days'` を発行、UI にフィルタ追加）

### 優先度: **高**

院長が最も聞く悩み「リピート率が上がらない」に直接刺さる施策。実装コストに対して ROI が高く、毎月の売上評価にもすぐ効果が出る。

## 提案 2 — 誕生月 LINE 自動お祝いメッセージ（差し込み変数 + クーポン添付）

**観点:** ① 受付・院長が使いやすくなる

### 背景・きっかけ

美容サロン向け記事（tol-app.jp, 2025）では「誕生月のメッセージはリピート施策の中でコスパ最高」と断言されている。治療院向けCRM「kartte.jp」でも誕生日 LINE 配信の自動化が特集されており、「予約が増えた」という声が多数掲載されている。

- 参照: https://tol-app.jp/columns/1848
- 参照: https://kartte.jp/column/67ff064e16e535d26fcc1aa0

V-ARC には LINE 配信機能（`line-campaign.ts`, `line-marketing.ts`）はあるが、**誕生日を自動トリガーとした送信スケジューリング**は未実装。

### 提案内容

1. **設定画面**（`/admin/settings/`）に「誕生月 LINE 設定」タブを追加。
   - メッセージテンプレートを院長が自由記述（`{{氏名}}` 差し込み変数対応）。
   - 送信タイミング: 「誕生月の1日」「誕生日の3日前」など選択式。
   - 任意でクーポンコード（テキスト）を添付。
2. バックエンドで毎日 cron 的に（または Next.js の scheduled route + Supabase function で）誕生月該当者を抽出し、LINE 送信ジョブをキューに入れる。
3. 送信履歴は `reminders.ts` の仕組みと統合して管理。

### 期待できる効果

- 院長・受付が何もしなくても毎月誕生日フォローが自動で走る。
- 誕生月限定クーポンでキャンペーン来院数の増加が見込める。

### 実装イメージ

- 関連ファイル: `src/app/actions/reminders.ts`（定期発火ロジック参考）、`src/app/actions/line-campaign.ts`（送信処理流用）、`src/app/actions/adminCustomers.ts`（誕生日フィールドが存在することを確認）
- 難易度: **小〜中**（顧客テーブルに誕生日があれば月初に抽出クエリ → 既存 LINE 送信 API を呼ぶだけ）

### 優先度: **高**

設定は1回だけ、あとは自動。スタッフの手間ゼロで患者との接点が毎月生まれる。

## 提案 3 — スタッフ達成バッジ & 称号システム（リーダーボード拡張）

**観点:** ③ スタッフ管理がしやすく、モチベーションが上がる

### 背景・きっかけ

ゲーミフィケーション研究（PBL: Point / Badge / Leaderboard）では、ポイントとランキングだけではモチベーションが「慣れ」で下がりやすく、**バッジ（実績証明）** の追加が継続的な動機付けに有効とされる（sofia-inc.com, 2026）。
海外では Square Appointments がスタッフごとのパフォーマンスレポートを持ち、SimplyBook.me がバッジに近いマイルストーン機能を持つ。

- 参照: https://www.sofia-inc.com/blog/12931.html
- 参照: https://seminars.jp/media/954

現在の V-ARC リーダーボード（`/admin/leaderboard/`）はポイント合計ランキングのみ。バッジ概念は未実装。

### 提案内容

バッジを 3 カテゴリで定義（初期セット）:

| バッジ名 | 条件 | アイコン |
|---------|------|--------|
| ファースト対応 | 初めて予約を1件作成 | 🎯 |
| 100件の手 | 累計アクション 100 件 | 💯 |
| 連続出勤 5 日 | 5 日連続で出勤記録 | 🔥 |
| 月間MVP | その月のランキング1位 | 👑 |
| 売上マスター | 累計売上記帳 50 件 | 💰 |
| 無遅刻30日 | 30 日間遅刻なし | ⭐ |

1. **バッジ定義テーブル** を Supabase に追加（`staff_badges`, `staff_earned_badges`）。
2. **リーダーボード画面**にスタッフごとの獲得バッジをアイコンで表示。
3. バッジ初取得時に **トースト通知** をスタッフの画面に表示（「🎉 新しいバッジを獲得しました！」）。
4. 院長向けに「全スタッフのバッジ一覧」サマリー表を追加。

### 期待できる効果

- ランキングが変動しない期間でも「バッジを貯める」という新しい達成動機が生まれる。
- 新人スタッフが「ファースト対応バッジ」を取れると早期に院のオペに馴染む効果がある。

### 実装イメージ

- 関連ファイル: `src/app/admin/leaderboard/page.tsx`（UI拡張）、`src/app/actions/security.ts`（`getLeaderboard` にバッジデータ結合）、Supabase マイグレーション追加
- 難易度: **中**（テーブル追加＋バッジ付与ロジックをサーバーサイドで管理）

### 優先度: **中**

既存リーダーボードの延長線で実装でき、スタッフのエンゲージメント施策として費用対効果が高い。

## 提案 4 — 患者「来院間隔スコア」と離脱リスクゲージ

**観点:** ② データ分析・経営判断がしやすくなる ／ ① 受付が使いやすくなる

### 背景・きっかけ

接骨院向け比較記事（rehasaku.net, 2026）で紹介される競合システムは軒並み「離脱防止」機能を強調している。海外の Square Appointments では「client retention」レポートが標準搭載されており、来院間隔に基づいてリテンション率を可視化している。

- 参照: https://rehasaku.net/media/receipt/4091/
- 参照: https://www.getapp.com/customer-management-software/a/square-appointments/

V-ARC の分析画面（`/admin/analytics/`）は月次比較・曜日別・メニュー別の集計はあるが、「患者 1 人ひとりの来院間隔」を軸にした離脱リスク可視化は存在しない。

### 提案内容

1. **顧客テーブル**に `avg_visit_interval_days`（平均来院間隔）と `risk_score`（0〜100）を計算カラムまたは Supabase ビューで追加。
   - スコア計算: `(今日 - 最終来院日) / avg_visit_interval_days * 100`（100以上で「要注意」）
2. **顧客一覧**（`CustomersTable.tsx`）に「リスクゲージ」カラムを追加。
   - 緑: 次回来院予定内 / 黄: 10日超過 / 赤: 30日超過
3. **ダッシュボード**（`DashboardClient.tsx`）に「今日の要フォロー患者 TOP 5」ウィジェットを追加。
4. 患者詳細画面（既存）に「この患者の来院間隔グラフ（過去12回分）」を追加。

### 期待できる効果

- 院長・受付が「誰が来なくなりそうか」を毎朝ひと目で確認できる。
- 休眠化する前の早期フォローが可能になり、離脱率が下がる。

### 実装イメージ

- 関連ファイル: `src/app/actions/analytics.ts`（来院間隔集計クエリ追加）、`src/app/admin/customers/CustomersTable.tsx`（カラム追加）、`src/app/admin/dashboard/DashboardClient.tsx`（ウィジェット追加）
- 難易度: **中**（Supabase 上で来院履歴をウィンドウ関数で集計、フロントはカラー分けゲージ表示）

### 優先度: **高**

「リピート率を上げたい」という院長の課題に対して、行動指針が毎日の業務動線に組み込まれる。提案1（休眠リスト）と組み合わせると特に強い。

## 提案 5 — スタッフ週次コンディション自己申告 & 院長モニタリング

**観点:** ③ スタッフ管理がしやすく、モチベーションが上がる

### 背景・きっかけ

スタッフの「突然の退職」「モチベーション低下」は院の運営に深刻な影響を与える。2025〜2026 年の HR テック領域では「パルスサーベイ（週次の短いアンケート）」が 1on1 ツールとして定着しており、Workship Magazine（goworkship.com）でも「継続的なコンディション確認がエンゲージメント向上の鍵」と紹介されている。日本のゲーミフィケーション事例記事（xrcloud.jp, 2025）でも「インナーリワード（達成感・成長実感）」を院長が可視化することの重要性が述べられている。

- 参照: https://goworkship.com/magazine/gamify_without_gimmicks/
- 参照: https://xrcloud.jp/blog/articles/business/27754/

V-ARC には `attendance.ts`（出勤管理）・`staff-daily-tasks.ts`・`shift-reminders/page.tsx` はあるが、スタッフの**主観的なコンディション（心身の状態・モチベ）を定期的に収集・集計する**機能は存在しない。

### 提案内容

1. **スタッフ向けページ**（`/admin/my-schedule/` または新規 `/admin/my-checkin/`）に「今週のコンディションチェック」フォームを追加。
   - 入力は週1回（月曜日にバナー表示）。
   - 3 項目（各 1〜5 のスライダー）: ①体調 ②モチベーション ③職場への満足度。
   - 任意の自由記述（「院長に一言」欄、院長のみ閲覧可）。
2. **院長向けモニタリング画面**（`/admin/settings/staff-schedule/` 新タブ、または独立ページ）:
   - 全スタッフの今週平均スコアをレーダーチャートで可視化（既存の evaluation ページのチャートを流用）。
   - スコアが先週比 20% 以上低下したスタッフを「要確認」としてハイライト。
3. 集計データは Supabase に保存し、過去8週分のトレンドグラフを表示（院長のみ）。

### 期待できる効果

- スタッフが「見てもらっている」という感覚を持ち、心理的安全性が高まる。
- 院長が早期に「しんどい」スタッフを把握し、1on1 のタイミングを逃さない。
- 離職率の低下が長期的な採用・育成コスト削減につながる。

### 実装イメージ

- 関連ファイル: `src/app/admin/my-schedule/page.tsx`（UI追加）、`src/app/actions/staff-daily-tasks.ts`（記録ロジック参考）、`src/app/admin/evaluation/page.tsx`（レーダーチャートコンポーネント流用）
- Supabase に `staff_pulse_surveys` テーブルを新規追加
- 難易度: **小〜中**（フォーム + 集計クエリ + レーダーチャート再利用で完結）

### 優先度: **中**

実装が軽量かつ、スタッフへの「気にかけている」メッセージになる。スタッフが複数院にまたがるボール接骨院グループでは特に効果的。
